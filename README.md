# @rolla-health/react-native-sdk

React Native wrapper for the Rolla SDK — modal-only integration of the Rolla Health & Fitness SDK in React Native apps.

## Installation

```sh
npm install @rolla-health/react-native-sdk
```

## Usage


```js
import { multiply } from '@rolla-health/react-native-sdk';

// ...

const result = await multiply(3, 7);
```
